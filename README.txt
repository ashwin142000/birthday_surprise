HOW TO USE
1. Put your pictures in the "photos" folder and name them 1.jpg, 2.jpg, 3.jpg ... (png/webp/jpeg also work).
   Number them in the order you want them shown. No limit on how many.
2. Open index.html in a text editor and change the CONFIG block at the top (name, message, captions, letter).
3. Upload the WHOLE folder (index.html + photos folder) to a GitHub repo.
4. Settings > Pages > Deploy from branch "main" > Save. Share the link.
Test locally with:  python -m http.server   then open http://localhost:8000
(Opening index.html by double-click may block photo auto-detection in some browsers.)
